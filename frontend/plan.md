1. Provide a robust backend API for student record management

## Data Models

### Student Entity

```json
{
  "id": 1,
  "name": "John Doe",
  "email": "john@example.com",
  "age": 20
}
```

**Student Struct Definition**:
```go
type Student struct {
  Id    int64  `json:"id"`
  Name  string `json:"name" validate:"required"`
  Email string `json:"email" validate:"required"`
  Age   int    `json:"age" validate:"required"`
}
```

**Validation Rules**:
- `name`: Required field, non-empty string
- `email`: Required field, non-empty string (format validation recommended for frontend)
- `age`: Required field, positive integer
- `id`: Auto-generated by database on creation

## API Specification

### Base URL
```
http://localhost:8082
```

### Endpoints

#### 1. Create Student
**Endpoint**: `POST /api/students`  
**Purpose**: Create a new student record  
**Content-Type**: `application/json`

**Request Body**:
```json
{
  "name": "Alice Johnson",
  "email": "alice@example.com",
  "age": 21
}
```

**Success Response** (201 Created):
```json
{
  "id": 5
}
```

**Error Response** (400 Bad Request - Validation Failed):
```json
{
  "error": {
    "field_errors": {
      "name": "required",
      "email": "required",
      "age": "required"
    }
  }
}
```

**Error Response** (400 Bad Request - Empty Body):
```json
{
  "error": "Empty body"
}
```

---

#### 2. Get Student by ID
**Endpoint**: `GET /api/students/{id}`  
**Purpose**: Retrieve a specific student by ID  
**Path Parameters**:
- `id` (integer, required): Student ID

**Success Response** (200 OK):
```json
{
  "id": 1,
  "name": "John Doe",
  "email": "john@example.com",
  "age": 20
}
```

**Error Response** (400 Bad Request - Invalid ID):
```json
{
  "error": "Invalid ID format"
}
```

**Error Response** (500 Internal Server Error):
```json
{
  "error": "Failed to retrieve student"
}
```

---

#### 3. Get All Students
**Endpoint**: `GET /api/students`  
**Purpose**: Retrieve all student records  
**Query Parameters**: None (currently)

**Success Response** (200 OK):
```json
[
  {
    "id": 1,
    "name": "John Doe",
    "email": "john@example.com",
    "age": 20
  },
  {
    "id": 2,
    "name": "Jane Smith",
    "email": "jane@example.com",
    "age": 19
  }
]
```

**Error Response** (500 Internal Server Error):
```json
{
  "error": "Failed to retrieve students"
}
```

## API Integration Guide for Frontend

### Request Headers
```
Content-Type: application/json
Accept: application/json
```

### Error Handling
Frontend should handle:
- Network errors (Connection timeout, DNS failure)
- HTTP status codes (400, 404, 500)
- Validation errors (Field-specific messages)
- Empty responses

### Common HTTP Status Codes
- `200 OK` - Successful GET request
- `201 Created` - Successful POST request
- `400 Bad Request` - Invalid request data or validation failure
- `500 Internal Server Error` - Server-side error
